# v0.21 Bootstrap Migration Validation

## Scope

v0.21 is the trusted one-time bridge from the physical v0.9 RootTools runtime to the modern RootTools device-management stack on the reference iOS 16 Dopamine device.

The migration does **not** add raw root shell, caller-selected executable/argv, or a public privileged listener.

## Bootstrap defects addressed

The physical v0.9 updater failed because:

- its launchd environment could not resolve Procursus `tar` for `dpkg-deb`;
- it targeted the wrong launchd domain for a Dopamine rootless LaunchDaemon.

The migration preserves the existing Owner R2 `device.self-update.schedule` authorization and verifies the local DEB against the device-side staged SHA-256 before extracting the candidate updater.

## Foreground App registration finding

The Root Tools bundle and executable remained valid on disk, but LaunchServices/SpringBoard registration became stale during updater experimentation and the Home Screen icon disappeared.

Validation proved:

- `/var/jb/Applications/RootTools.app` existed;
- Bundle ID remained `com.arthur.roottools.ios`;
- the binary remained arm64/ad-hoc signed;
- `uicache` re-registration succeeded;
- the app could be launched through `uiopen`;
- a SpringBoard refresh restored the visible Home Screen app.

This establishes a new production requirement: Self-Updater qualification must include foreground App discoverability/registration, not only daemon version health.

## Remaining boundary

v0.21 still owns the updater as a child of `roottools-execd`. A later physical update demonstrated that this process can be terminated when execd is booted out during switching. v0.22 addresses that by dispatching the updater through its independent launchd service.
