# v0.9 Runtime Observation Validation

## Local acceptance

- Control Plane test: pass.
- Provider Registry test: pass, including Frida/ElleKit capability bindings.
- Package Controller test: pass.
- Update Controller test: pass.
- Runtime Observer test: pass with deterministic Frida and ElleKit dpkg package/version fixtures.
- HTTP contract: pass for both runtime endpoints and all unsafe-exposure booleans.
- iOS 16 arm64 daemon/updater build: pass.
- iOS 16 Release App build: pass with Providers UI runtime facts.

## Contract assertions

Frida:

- `providerId=runtime.frida`;
- `scriptExecutionExposed=false`;
- `arbitraryAttachExposed=false`;
- package/version and process facts are observations only.

ElleKit:

- `providerId=runtime.ellekit`;
- `rawHookAPIExposed=false`;
- `arbitraryInjectionExposed=false`;
- fixed rootless component paths are observed rather than supplied by the caller.

## Physical-device boundary

The reference iPhone still runs the old v0.3 daemon. The existing device reports Frida/ZXTouch/SSH headless services available, but the new v0.9 runtime endpoints do not exist on that installed daemon. v0.9 physical acceptance must therefore wait until a bootstrap build containing the v0.8+ updater is installed. No v0.9 physical result is claimed from the old daemon.
