# v0.6 Package Controller Validation

## Status

Package Controller implementation is complete in source and locally validated. Physical v0.6 deployment is not claimed: the connected iPhone still runs the previously installed v0.3 daemon because the current host execution policy blocks executable/package installation before those commands reach the device.

## Automated validation

The local suite covers:

- Control Plane policy/idempotency/revision;
- Provider Registry and package-provider planning;
- Package Controller begin/chunk/commit/catalog/discard;
- strict sequential package chunk offsets;
- SHA-256 success and mismatch handling;
- dynamically generated IPA ZIP metadata inspection with no external `unzip` dependency;
- HTTP staging through base64 chunks;
- Agent cannot self-confirm R2 package installation;
- owner-confirmed install fails before execution when its provider is unavailable in the macOS test runtime;
- iOS 16 Release build including CryptoKit/fileImporter Packages UI.

Expected current results:

- `control_plane_test: PASS`
- `provider_registry_test: PASS`
- `package_controller_test: PASS`
- `http_contract_test: PASS`
- `RootTools contract tests: PASS`
- iOS Release `BUILD SUCCEEDED`

## Physical acceptance required after deployment

1. `/v1/hello` reports `daemonVersion=0.6.0` and `packageController=true`.
2. `/v1/providers/catalog` reports Procursus and TrollStore provider readiness accurately.
3. Stage a small benign DEB through Mac Device Service; verify hash and detected Package ID.
4. Owner-confirmed DEB install returns `providerId=bootstrap.procursus` and passes `dpkg-query` post-condition.
5. Stage a benign IPA/TIPA; verify detected `CFBundleIdentifier`.
6. Owner-confirmed IPA/TIPA install returns `providerId=package.trollstore` and passes installed-bundle post-condition.
7. Agent-token attempts to self-confirm package install remain `confirmation_required` with `executed=false`.
8. Package bytes and caller-supplied paths never appear in audit records.
9. Existing UID501 UI / UID0 daemon, lock-aware automation, TCC, lifecycle, and R3/raw-shell regressions remain green.

## Not yet claimed

- automatic physical deployment of v0.6 from this chat execution environment;
- RootTools self-update rollback helper;
- generic DEB uninstall/rollback;
- alternate jailbreak/package-provider qualification.
