## Scope

v0.22 adds the first Owner-initiated Tailnet Remote Session and hardens the independent self-update path.

## Remote Access invariants

- session start is an Owner action;
- listener address must be a detected Tailscale IPv4 address in `100.64.0.0/10`;
- ordinary Wi-Fi/cellular addresses and `0.0.0.0` are not valid bindings;
- session selects exactly one active Named `host` Principal;
- Owner credential is rejected on the remote listener;
- legacy Agent credential is rejected on the remote listener;
- a different Named Principal is rejected;
- selected Host Principal still requires exact R0/R1 grants;
- Principal revoke invalidates the session;
- sessions have bounded expiry;
- Developer Mode does not widen remote Principal authority.

## Task runtime regression

Queued/retrying work is selected ahead of already-blocked `waiting_for_unlock` work so one locked UI task cannot cause indefinite queue head blocking. UI-required tasks still converge to `waiting_for_unlock` and do not bypass the passcode.

## Self-Updater regression

The updater is dispatched through its independent launchd service rather than depending on the serving execd process lifetime. App registration/discoverability is treated as a deployment health requirement alongside daemon version health.

## Physical-device boundary

The reference phone was physically proven healthy on v0.21 before it left the development host. v0.22 has not yet completed physical installation and off-USB Tailnet qualification because the reference iPhone's Tailscale node was offline and no USB/LAN control path remained available.

Do not claim v0.22 physical Remote Access qualification until all of the following are proven:

1. device reports daemon `0.22.0` / UID 0;
2. Root Tools foreground app remains registered and openable;
3. Tailscale is online;
4. Owner starts a bounded Remote Session;
5. trusted Host connects with the selected Named Principal while USB is disconnected;
6. remote status/performance and an authorized R1 task succeed;
7. Owner token and non-selected Principal are rejected remotely;
8. stop/expiry/revoke closes remote authority.
