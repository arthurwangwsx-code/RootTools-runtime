# v0.23.0-2 Offline Release Qualification

Date: 2026-09-01

## Decision

v0.23.0-2 is ready as a private draft release candidate. All gates that can be
proved without a jailbroken physical iPhone are automated and passing. This
decision does not qualify Dopamine, rootless launchd jobs, TrollStore, USB,
Tailnet, credential cutover or rollback on the reference phone.

## Implemented release controls

- Public source and private credential-bearing artifacts have separate,
  fail-closed repository targets.
- The `installed` credential profile remains untouched; candidate builds use
  `candidate-v0.23.0-2` with distinct Owner and Agent credentials.
- Build stamps and manifests carry profile name and SHA-256 fingerprints only.
- Daemon hello/status and Self-Updater health checks distinguish
  `daemonVersion=0.23.0` from exact `packageVersion=0.23.0-2`.
- Candidate DEB/IPA inspection proves target credentials are present where
  required and installed credentials are absent.
- The retained v0.23.0-1 DEB is verified as an installed-profile rollback
  artifact.
- Release packaging is deterministic for the same committed inputs and
  `SOURCE_DATE_EPOCH`.

## Repeatable evidence

Run the complete contract, device Release-build and Simulator fixture gate:

```bash
Scripts/validate-simulator.py \
  --credential-profile candidate-v0.23.0-2 \
  --visual-inspection completed
```

The ignored, mode-`0600` receipt is written to
`build/validation/roottools-0.23.0-2-simulator.json`. It records:

- full contract suite: passed;
- unsigned `iphoneos` Release build: passed;
- Simulator Release build/install/launch: passed;
- candidate Owner authentication: passed;
- exact fixture package identity: passed;
- screenshot path and SHA-256;
- physical-device scope: `pending-not-substituted`.

Prepare the credential cutover evidence from the exact release assets:

```bash
python3 Scripts/prepare-credential-migration.py \
  --to-profile candidate-v0.23.0-2 \
  --deb build/packages/roottools_0.23.0-2_iphoneos-arm64.deb \
  --ipa build/packages/RootTools_0.23.0-2.ipa \
  --rollback-deb build/packages/roottools_0.23.0-1_iphoneos-arm64.deb
```

The ignored, mode-`0600` state is
`build/qualification/credential-migration-state.json`. The release manifest and
downloaded asset checksums are authoritative for final commit/artifact identity;
do not copy transient local hashes into this source document.

## Remaining boundary

Only the gates in `v0.23.0-2-physical-ledger.md` remain. The GitHub candidate
must stay draft until those gates are closed. The frozen legacy iOS snapshot and
installed-profile rollback artifact must remain recoverable.
