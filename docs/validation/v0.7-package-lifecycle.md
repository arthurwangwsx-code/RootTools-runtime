# v0.7 Package Lifecycle Validation

## Scope

v0.7 extends the typed Package Controller with managed uninstall, retained-artifact rollback, and package lifecycle history. It does not expose generic uninstall-by-bundle/package-name APIs: the target must be a RootTools package record.

## Lifecycle model

- `ready` — verified artifact can be installed.
- `installed` — active managed artifact.
- `retained` — previous active verified artifact kept for rollback.
- `uninstalled` — managed target removed; artifact retained for reinstall.
- `discarded` — staged artifact intentionally removed.

When one verified artifact becomes active, any previous `installed` record for the same package/bundle identifier becomes `retained` atomically in the package ledger.

## Typed R2 operations

- `device.package.uninstall-deb` -> `bootstrap.procursus` -> fixed `dpkg -r <managed-id>`.
- `device.package.uninstall-ipa` -> `package.trollstore` -> fixed `trollstorehelper uninstall <managed-bundle-id>`.
- `device.package.rollback-deb` -> reinstall retained DEB, allowing downgrade only for this rollback path.
- `device.package.rollback-ipa` -> reinstall retained IPA/TIPA with the pinned TrollStore helper contract.

All four operations require daemon-enforced owner confirmation and verify the resulting installed/absent state.
