# v0.16 Performance Observation Validation

## Capability

`device.performance.observe` is an R0 semantic capability bound to the Darwin provider. It exposes a structured `/v1/performance` snapshot rather than shell output.

The snapshot contains:

- uptime;
- logical CPU count;
- 1/5/15 minute load average when available;
- total/free/active/inactive/wired memory using host VM statistics;
- root and `/var` free bytes;
- RootTools daemon PID and resident memory;
- process count;
- active durable task count;
- ready/total Provider counts.

## Automated acceptance

- Provider binding contract maps the capability to `ios.darwin`.
- HTTP contract verifies schema, CPU count, uptime, daemon PID, process count and Provider summary.
- the endpoint is subject to global Owner policy and exact Principal Grants like every other R0 observation.
- the full RootTools contract suite remains green under strict C warnings.

## Product acceptance

- Device > Performance presents structured cards rather than a raw monospaced dump.
- Mac Device Service exposes the `performance` command.

## Physical-device boundary

The reference iPhone still runs v0.9.0. v0.16 physical resource values are not claimed until the trusted updater deploys this line.
